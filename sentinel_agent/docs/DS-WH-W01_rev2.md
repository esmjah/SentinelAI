# Wellhead and X-mas tree datasheet (synthetic)

## 1. Equipment
| Component | Rating | Notes |
|---|---|---|
| Tubing-head spool with A-annulus outlet valves | 5000 psi (344.7 bar) | Holds the tubing hanger |
| Casing-head spool with B-annulus outlet valves | 3000 psi (206.8 bar) | Holds the production-casing hanger and pack-off |
| Master valve | 5000 psi | Hydraulically actuated, fail-safe closed; final element of the safety instrumented system |
| Production wing valve | 5000 psi | Manual |
| Production choke | adjustable, bean size in 1/64 in | Effective opening grows with trim erosion |

## 2. Seals
The tubing hanger has elastomer seals with test ports between them. The casing-hanger pack-off seals the
A-annulus from the B-annulus at surface; it can be tested through its own test port.
