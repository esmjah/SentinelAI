# Production packer datasheet (synthetic)

## 1. Identification
Hydraulic-set, retrievable production packer for 9-5/8 in 47 lb/ft casing with 4-1/2 in tubing.
Set at 2300 m measured depth in well W01.

## 2. Ratings
| Property | Value |
|---|---|
| Differential pressure rating | 5000 psi (344.7 bar) |
| Validation grade | ISO 14310 V0 (gas-tight, zero bubbles) |
| Element material | HNBR |
| Temperature range | 4 to 121 degC |

## 3. Operating notes
Tubing movement from heating and ballooning changes the axial load on the packer. The completion
design must keep the packer within its load envelope during start-up and shut-in. An element leak or
unseating opens a path between the producing zone and the bottom of the A-annulus.
