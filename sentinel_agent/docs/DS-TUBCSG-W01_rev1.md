# Tubing and casing datasheet (synthetic)

## 1. Strings
| String | Size and grade | Burst | Collapse |
|---|---|---|---|
| Production tubing | 4-1/2 in 12.6 lb/ft L80 | 8430 psi (581.2 bar) | 7500 psi (517.1 bar) |
| Production casing | 9-5/8 in 47 lb/ft L80 | 6870 psi (473.7 bar) | 4750 psi (327.5 bar) |
| Intermediate casing | 13-3/8 in 68 lb/ft K55 | 3450 psi (237.9 bar) | 1950 psi (134.4 bar) |

## 2. Wall loss
Burst capacity falls roughly in proportion to the remaining wall thickness; collapse capacity falls
faster, roughly with the square of the remaining wall. Any caliper finding must be fed into the MAASP
calculation.
