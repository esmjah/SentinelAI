# Well integrity test catalogue (revision 4)

## 1. Classes of test
| Class | Meaning |
|---|---|
| C | Online screening from existing data; no cost |
| B | Discriminating test with an operator action |
| A | Confirmatory test or log; verifies a barrier element |

## 2. Planning costs
| Test | Class | Planning cost (NOK) | Duration |
|---|---|---|---|
| Annulus top-up volume | B | 30,000 | 2 h |
| A- or B-annulus bleed-down and build-up | B | 50,000 | 12 h |
| Bled-gas sampling and composition | B | 80,000 | lab |
| Shut-in communication test | B | 300,000 (deferred production) | 22 h |
| Annulus outlet valve and seal leak test | A | 30,000 | 2 h |
| Choke inspection | A | 40,000 | 4 h |
| Valve closure function test (DHSV, master valve) | A | 50,000 | 2 h |
| DHSV inflow test | A | 100,000 | 4 h |
| B-annulus pressure test | A | 1,000,000 | 12 h |
| Caliper or electromagnetic thickness log | A | 1,200,000 | 24 h |
| A-annulus pressure test (MIT-A) | A | 1,500,000 | 12 h |
| Temperature and noise leak-detection log | A | 1,500,000 | 24 h |
| Tubing pressure test against a plug | A | 2,000,000 | 24 h |
| Cement bond or ultrasonic log | A | 2,500,000 | 24 h |
